# Виджет банковских операций

## Описание проекта

Проект представляет собой набор функций для обработки данных о банковских операциях клиента.

В проекте реализованы функции для:

- маскировки номеров банковских карт и счетов;
- обработки информации о банковской карте или счёте;
- фильтрации банковских операций по статусу;
- сортировки банковских операций по дате.

## Структура проекта

Основные функции проекта находятся в директории `src`:

### `masks.py`

Содержит функции для маскировки банковских реквизитов:

`get_mask_card_number()` — маскирует номер банковской карты;
`get_mask_account()` — маскирует номер банковского счёта.

### `widget.py`

Содержит функции для обработки данных:

`mask_account_card()` — определяет тип банковского реквизита и возвращает его замаскированное представление;
`get_date()` — преобразует дату в формат `ДД.ММ.ГГГГ`.

### `processing.py`

Содержит функции для обработки списка банковских операций:

`filter_by_state()` — фильтрует операции по значению ключа `state`;
`sort_by_date()` — сортирует операции по дате.

## Установка
Клонируйте репозиторий:

`git clone git@github.com:alenasedykh/my_prj.git`
Установите зависимости:

`poetry install`

## Использование
Функции можно импортировать из соответствующих модулей директории src:
`from src.masks import get_mask_card_number, get_mask_account`
`from src.widget import mask_account_card, get_date`
`from src.processing import filter_by_state, sort_by_date`


## Тестирование

Для запуска автоматических тестов используется `pytest`.
Запустить все тесты:
```bash
poetry run pytest
```

### Проверка покрытия кода

Для проверки покрытия используется `pytest-cov`.

Запустить тесты и вывести отчёт о покрытии в терминале:

```bash
poetry run pytest --cov=src --cov-report=term-missing
```

Создать HTML-отчёт о покрытии:

```bash
poetry run pytest --cov=src --cov-report=html
```

После выполнения команды HTML-отчёт будет доступен в директории `htmlcov`. Чтобы просмотреть его, откройте файл `htmlcov/index.html` в браузере.

### Проверка качества кода

Проверить стиль кода с помощью `flake8`:

```bash
poetry run flake8 src tests
```

Проверить типы с помощью `mypy`:

```bash
poetry run mypy src tests
```

Проверить порядок импортов с помощью `isort`:

```bash
poetry run isort --check-only src tests
```
